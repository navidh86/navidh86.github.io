# navidh86.github.io

Personal academic website of Navid Bin Hasan, served by GitHub Pages at <https://navidh86.github.io>.

It is a single static page (`index.html` + `assets/`) with no build step. To preview locally, open `index.html` in a browser, or run `python3 -m http.server` in the repo root and visit <http://localhost:8000>.

Based on the [vCard personal portfolio template](https://github.com/codewithsadee/vcard-personal-portfolio) by codewithsadee, used under the MIT License (see `LICENSE`).
